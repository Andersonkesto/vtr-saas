# VTR SaaS - Gestão Inteligente de Frotas

O **VTR SaaS** é uma plataforma moderna e escalável baseada em nuvem, projetada especificamente para o controle operacional e monitoramento de viaturas. 

Diferente de sistemas tradicionais, o **VTR SaaS** elimina a necessidade de infraestrutura local, oferecendo uma solução completa como serviço (Software as a Service) para batalhões e unidades que buscam eficiência, transparência e agilidade.

## 🚀 Principais Funcionalidades
- **Check-in/Check-out via QR Code:** Registro instantâneo de assunção e entrega de viaturas.
- **Gestão de Manutenção:** Acompanhamento de troca de óleo, inspeção G.A.L.O.P.E e registro de alterações.
- **BI & Analytics:** Dashboards em tempo real com estatísticas de uso, KM rodado e saúde da frota.
- **Monitoramento de Acessos:** Registro de logs de atividade, geolocalização e dispositivos.
- **Impressão de QR Codes:** Sistema integrado para download e impressão de etiquetas de identificação.

## 🛠️ Tecnologias
- **Frontend:** React + Vite (UI Responsiva e Premium)
- **Backend/Database:** Firebase Firestore (Cloud-Native)
- **Segurança:** Autenticação e regras de acesso em tempo real.

## 📱 Mobile-First
Projetado para ser utilizado diretamente no campo através de dispositivos móveis, garantindo que o policial na ponta tenha uma ferramenta ágil e confiável.
